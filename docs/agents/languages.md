# Languages and language practice

## Layout

- `language` (the 11 languages: codes, names, yes and stop words, a call's "but", acknowledgement and leave-taking words and the words that go on from them ("to", "naar"), the reasons for leaving that also complain (`LEAVING_UNCLEAR`), a caller's thanks (`THANKS`), the requests to end a call (`ENDING`, `ENDING_SOFT`), the words that say more is coming (`MORE_COMING`), her plain goodbyes (`GOODBYES`, `GOODBYES_UNTIL`), the stage directions never spoken or sent (`STAGE_DIRECTIONS`, `STAGE_STARRED`, `STAGE_SOFT`; `made_of`, the phrase check calls shares), the function words and negations her own voice is told by, the negations also guarding the practice recap, and the words that ask for a code or a password, `SECRET_WORDS`; one at a time)
- `babble` (language practice, /babble: the session in the state table, its own conversation, the practice turn's broken-reply guard and tidy reply, the recap's call and its checks in code, the idle loop with the quiet-hours hold and the lock's)

## Commands

- Language-practice cases (real model, only by name): `uv run python -m evals.gemma_suite practice` (all 18) or `practice_nl` (one language's two), from the tutor test's sets in `evals/practice/`; run it twice and read each language's numbers

## Rules

- Language: one at a time; the language changes only by the user's typed `/language` (never a voice note's transcript, never on a call, never by Gemma: no tool exists). The config's `language` is the starting value; the state table's wins. English adds nothing to the rules and its voice requests are byte-identical to before (no query, no field); another language replaces "reply in the user's language" with one line. Code-written text stays English; on a call, code's own words (the device question, results, rare lines) are spoken in English so a yes never confirms something unclear, and in another language a turn that waits for a device's yes says and keeps only code's question, in a text and on a call (a Dutch Gemma claimed a switch before the yes); in an answer whose `set_reminder` stored nothing, code's line why is said in English after her words (see Reminders).
- The Language rule's "see Reminders": that rule is in `docs/agents/memory-initiative.md`.
- Language practice (`babble`): only the user's typed `/babble` starts it (never a voice note, a call or Gemma: no tool); it ends with `/babble off`, the end of a practice call or 30 minutes without a practice message. One session at a time, for the ACI that started it (other allowed users stay in chat; another one's `/babble` is refused while it runs and sends its held recap first when it ended), in its own conversation (`conversations.kind = 'practice'`, schema v8: never `current_conversation`, `/new` leaves it, never summarised), which idle learning, check-ins, the look back and the history search leave out (`store.user_messages_after`, `user_messages_since`, `search`); a practice message still counts as the user writing (busy gates, reminder retries), and her own messages wait while it runs (the initiative gate's `practice`). No tools: the practice rules mention none (`prompts._practice_rules`: the practice line in place of the language line, no tool sections or Memory tool bullets, `PRACTICE_NO_TOOLS`) and Brain's `_practise` offers none; a broken reply (empty, only `---` or only a `→` line) is asked once more, then replaced by the language's `PRACTICE_FALLBACK` (never kept); `babble.tidy` drops `---` lines and keeps one `→` line, first, none in a reply to a voice note or a call and none whose words the user already wrote; a `→` line that shows the user's wrong form next to the right one ("abita <abitano>", "Levanto -> Te levantas", "la problema, il problema") keeps only the right one, or goes when that cannot be read safely (its wrong part is not the user's words; `babble._corrected`); a "Noted:" gets `PRACTICE_NOTHING_SAVED`, and a claimed reminder gets `PRACTICE_NO_REMINDER` only when the user asked for one (this message or the one before: a roleplay line is no promise) and only in her own words: never the `→` line (the user's sentence, corrected) nor a claim-shaped sentence the user wrote that she repeats (`brain._practice_claims`). Voice notes and calls are heard and spoken in the practised language; only a call the user makes during practice is a practice call (`_Call.practice`, passed to `call_turn`): texts typed during it are answered as practice first (`PRACTICE_DRAIN_S`), then its end (after a turn) ends practice and sends the recap instead of the call summary; a call she places for a reminder is an ordinary call and practice keeps running. The recap's points are checked in code (`babble.keep_point`: said verbatim in a turn, a real and small change (a pure reorder, or the word rule; Japanese max(6, half the characters)), a negation kept, and a why that neither thinks aloud (at a sentence start, unquoted) nor says the user's form is right (no-error phrases unless the correction is quoted; "is correct" only when the user's words are quoted, not the correction, and not negated)) and dropped ones are logged as counts; an answer cut off at its token limit keeps its complete points (`babble.recap_items`), and one with none, or not the schema's JSON, is asked once more with `PRACTICE_RECAP_SHORT_WHY` (one short why each), else the note says no recap came; the recap is a note stored with the session cleared in one transaction (never written twice); an idle end says so in the recap, which waits for the end of quiet hours or the user's next message (sent before it is answered), `/quiet` never holds it. `/language` is refused during practice. `/lock` stops practice too: no practice answer, a practice call hung up like any call, the idle loop waits (`Babble(locked=…)`), and a recap that falls due meanwhile (a practice call's end, an idle end after `/unlock`) is neither written nor sent until `/unlock` (`Babble.finish` checks before and after Gemma writes it, so a lock during that call keeps it held). Practice messages stay in `messages` (their own conversation); no list of mistakes; state keys `babble:last` and `babble:session` only.

## Gotchas

- Speech in English and in the other ten languages (VoiceCore `SpokenEnglish`, `SpokenLanguage`, the packs): see `docs/agents/calls.md`, Gotchas.
